# Phase6 — Safe real-film audio and scene review queue (2026-11-22)

## Goal and user journey
Film Review Agent has CLIP+Qwen tentative frame matches and 17 English Fatman ASR rows, but cannot yet author a verified real-film recap. Phase6 creates a PRIVATE, offline review experience on the authorized Windows workstation: listen to each original English utterance alongside its provisional Vietnamese translation; inspect the relevant continuous 30-second source excerpt; approve/reject original claim/translation separately. It does not automatically approve anything or generate TTS/release a film.

## Architecture
1. stage6/dialogue_review.py: build_dialogue_review_queue(pack, raw_asr, movie_sha, duration, windows) cross-validates each original ASR ID, English sentence SHA/text, timestamps and film SHA against Stage5 translation pack and raw read-only transcript. Never overwrites originals. Each row holds pending human English listening and Vietnamese semantic checks. Flag weak ASR and translation mistakes e.g., mailed "letters" translated to alphabet "chữ cái"; no automatic correction. Preview audio window is within original source clip, with padding not exceeding authorized 3x30s samples.
2. stage6/scene_proposals.py: build_scene_proposals(movie_sha, movie_duration, source_windows, detected_cuts) transforms actual ffmpeg scene-change timepoints (extracted from each existing 30s clip) into candidate shots in absolute original film time. Reject invalid/boundary/out-of-window/duplicates and cross-window time shifting. Status remains AUTO_SCENE_CANDIDATE_PENDING_VIDEO_REVIEW; no assumption a cut proves the scene narrative.
3. stage6/review_packet.py: build_review_packet(movie_sha, storyboard, source_catalog, scene_proposals, dialogue_queue) validates source film, every claim ID, source frame evidence text and time, scene-window containment and originals. It emits an unsigned request for user review (each visual claim plus all translated utterances), with stage6 frame-to-shot provenance; rejects arbitrary invented causal/violent claims. Crucially, all statuses remain PENDING and can_tts=false, can_render=false.
4. qa/phase6_workbench.py: reusable standalone, source-hash-pinned read-only runner using authorized prior QA and a new empty private output root. ffmpeg extracts 17 local padded original-audio preview WAV files; performs scene-cut detection of 3 existing 30-second clips; generates structured JSON + accessible offline HTML review page with audio controls and links to source footage, human-visible uncertainties and an unsigned JSON checklist. All movie/audio/text stays under private local Phase6 QA directory, excluded from GitHub. This script is NOT an approval-signing endpoint.

## Boundaries and acceptance
- No downloads, package installs, edits to old movie/old workspaces, merge to main, changes to 11 Agent Skills, fake human approval or public copyrighted media.
- Existing Phase5 Draft PR #9 remains the base. New feature branch and Draft PR only, source-only QA stats public.
- Technical success: all tests pass; actual Fatman source remains unchanged; exactly 17 English ASR rows with playable local previews; 3 source windows with real scene cut candidates; original Stage4/5 claim IDs in a 3-scene unapproved packet.
- Semantic story/voice/video production remains blocked until an independent person listens and verifies real film/translation and explicitly approves narration and pilot. Frame-anchored evidence is not full-film plot truth.
