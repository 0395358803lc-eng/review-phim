# Workflow: Ending Explained
**Format:** central mystery -> evidence -> alternative explanations -> conclusion calibrated to certainty.
**Intake:** film, exact ending question and spoiler permission.
**Evidence:** retrieve late scenes plus earlier setups/foreshadowing; label explicit dialogue vs interpretation vs outside commentary. If multiple plausible endings, say so; never invent a definitive solution.
**Visual:** scenes must support cited claims, don't show a reveal before corresponding line.
**Output:** evidence ledger + competing interpretations + script and QC. Flag uncertain canonical lore for independent verification with cited sources if external research approved.
