# Workflow: Movie Recap / Plot Compression
**Product:** causal recounting with original perspective, not a substitute copy of full movie.
**Editorial:** Hook -> protagonist/objective -> cause/consequence beats -> complications -> climax -> thematic wrap. Allow spoiler-full only when brief approves.
**Mandatory:** explicit chronology vs screen order, verify characters and actions, minimize extensive plot footage, add substantive voice/analysis rather than stitching source scenes.
**Quality risks:** wrong flashback order, unsupported motivations, death/twist spoilers, source footage dominance and reused-content policy.
**Deliverables:** causal graph mapping every beat to source timecodes, verified script/EDL, rights review, QC.
