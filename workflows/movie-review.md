# Workflow: Movie Review / Critical Commentary
**Product:** judgment-and-evidence review, not beat-by-beat replacement of film.
**Brief:** title, source file, position/thesis, spoiler policy, duration, audience, language, format, rights scope.
**Editorial outline:** opening provocative claim -> premise without excess recap -> 2–4 supported observations about writing/acting/cinematography -> counterpoint -> verdict -> takeaway.
**Production:** standard stages ingest -> evidence -> narrative -> script with claims/opinion labels -> match excerpt strictly to each analytical point -> voice/EDL/render/QC.
**Gate:** source-footage usage only as necessary to prove critique; no automated legal claim of fair use.
**Deliverables:** script, citations to scenes, selection rationale, rendered version(s), QC/rights summary.
